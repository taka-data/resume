## 自己PR

私の強みは、依頼された解決策をそのまま実行するのではなく、業務全体を見ながら本質的な課題を特定し、仕組みから改善することです。  
広告バナー制作プロジェクトでは、当初「AIで高成果広告を作りたい」という依頼を受けましたが、現場へのヒアリングを重ねた結果、真のボトルネックは納品フォルダの整理や確認工程にあると判断しました。そこで、AI導入そのものではなく、指示書構造や要件定義の進め方、制作管理の仕組みを見直しました。その結果、デザイナー工数15％削減、管理職の残業時間50％削減、年間約960万円のコスト削減につなげました。  
この経験から、個別の要望やツールだけを見るのではなく、バリューチェーン全体を捉えて、どこに本当のボトルネックがあるのかを見極めることに自分の強みがあると考えています。現在はAIやデータ分析の知識も広げていますが、技術そのものではなく、業務や経営上の成果につなげることを重視しています。

### I社　2026年4月 - 現在
_PM / DXコンサルタント_

#### ECサイト向けデータ分析AI エージェント開発 (2026年5月 - 現在)
**課題:** ECサイトの売上・行動データ分析が都度手作業で行われ意思決定に時間がかかっていたが、PM・メンバーにAWS経験者が不在で技術推進役が誰もいなかった  
**施策:** AWSを独学し、要件定義〜設計〜実装〜権限（IAM）付与までを一貫して担当。クライアントと直接コミュニケーションを取りながらマーケティング部門・DX部門など複数部署を横断して調整・実装を推進し、自然言語での問いかけに対してデータ分析結果を返す因果推論分析支援エージェントを構築  
**成果:** マーケ部門がDX部門を介さず自ら分析できる状態を実現し、部署間のコミュニケーションコストを解消  
**使用技術:** AWS (S3, Lambda, Bedrock, IAM等), Python, EconML
