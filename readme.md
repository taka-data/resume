## 自己PR

私は、表面的な要望の背景にある課題を見抜き、構造から解決策を設計することを強みとしています。例えば、広告バナー制作プロジェクトでは、当初「AIで高成果広告を作りたい」という依頼から始まりました。しかしヒアリングを重ねるうちに、真のボトルネックは納品フォルダの手作業整理とチェック工程にあると判明しました。私は課題を再定義し、クライアントへ率直に共有。指示書構造を再設計し、要件定義フェーズを新設した結果、残業時間を半減させ、年間約960万円のコスト削減を実現しました。

この経験から、「問題の本質は依頼の背後にある」と学びました。以後、顧客ヒアリングでは現場へ足を運び、真因を見抜く姿勢を徹底しています。同時に、新卒メンバーにはPBI（Product Backlog Item）の自記入を徹底。目的・受入基準・優先度を自ら定義させ、伴走しながら課題設定から実行まで支援することで、属人化を防ぎ、自律的に動けるチームを育成しました。

夜間MBAで学んだ戦略・会計・統計の知見を基盤に、「技術を導入して終わり」ではなく、**意思決定に結びつけるデータ活用**を追求しています。これからも、課題を定義し、仕組みとデータで組織の価値を底上げしていきます。
